# CreeperCatEvoV2 (Fabric 1.20.1)

## Игра
- Предмет `creepercat:feline_mutagen` («Сфера Первородного Кота») выдаётся только командой:
  `/give @s creepercat:feline_mutagen` или `/givecatcore`.
- ПКМ превращает вас в кота, повторный ПКМ — назад в человека.
- В облике кота ударьте крипера (ЛКМ или ПКМ пустой рукой в 4 блоках):
  кот встаёт на задние лапы и разрывает крипера на две половины.
- Каждое разрывание = +1 очко эволюции. Стадии: 1 (0–4), 2 (5–14), 3 (15+).

## Коты-помощники
Приручённые не-сидящие коты сами охотятся на криперов в радиусе 10 блоков.

## Сборка
JDK 17, Gradle 8.8, workflow GitHub Actions прилагается.
